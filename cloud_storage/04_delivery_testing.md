# 交付测试：云存储产品

## 概述

本文档定义类 MEGA 云存储产品的完整测试与交付策略，涵盖测试金字塔、测试用例矩阵、安全审计清单、性能基准指标、CI/CD 流水线及交付检查清单。

---

## 1. 测试策略

### 1.1 测试金字塔

```
           ┌──────┐
           │ E2E  │  5%   - 关键业务流程端到端测试
          ┌┴──────┴┐
          │Integration│ 20% - 微服务间 API 契约测试
         ┌┴──────────┴┐
         │  Unit Tests  │ 75% - 单元测试 + 组件测试
        └┴──────────────┴┘
```

### 1.2 各层测试目标

| 测试层 | 工具 | 覆盖目标 | 运行频率 |
|--------|------|----------|----------|
| **单元测试** | Go: testing + testify, TS: Vitest + React Testing Library, Dart: flutter_test | 行覆盖率 ≥80% | 每次提交 |
| **集成测试** | Go: httptest + dockertest, 契约测试: Pact | 每个服务接口 100% | 每次 PR |
| **E2E 测试** | Playwright (Web), Maestro (移动端) | 核心流程覆盖 | 每日 / 每次发布 |
| **性能测试** | k6, vegeta, Apache Bench | 关键接口 | 每周 + 发布前 |
| **安全测试** | OWASP ZAP, Trivy, 手动渗透 | 全量 | 每月 + 大版本前 |

## 3. 安全测试清单

### 3.1 自动化安全扫描

| 检查项 | 工具 | 频率 | 通过标准 |
|--------|------|------|----------|
| 依赖漏洞扫描 | Trivy / Snyk | 每次 CI | 无 Critical/High 漏洞 |
| SAST 代码扫描 | gosec (Go) / ESLint security (TS) | 每次 PR | 0 新增告警 |
| 容器镜像扫描 | Trivy | 每次构建 | 无 Critical 漏洞 |
| Web 应用扫描 | OWASP ZAP | 每周 | 无 High 风险 |
| 密钥泄露检测 | git-secrets / Gitleaks | 每次提交 | 0 命中 |
| TLS 配置检查 | testssl.sh / Qualys SSL Labs | 每月 | A 评级 |

### 3.2 手动渗透测试清单

| 类别 | 测试场景 |
|------|----------|
| **认证** | 暴力破解防护、JWT 伪造、Refresh Token 重放、会话固定 |
| **授权** | 水平越权（访问他人文件）、垂直越权（普通用户调用管理 API） |
| **注入** | SQL 注入、NoSQL 注入、命令注入（文件名） |
| **XSS** | 存储型 XSS（文件名/描述）、反射型 XSS（搜索参数） |
| **CSRF** | 关键操作无 CSRF Token |
| **文件上传** | 恶意文件上传、超大文件 DoS、文件名路径穿越 |
| **加密** | 中间人攻击（公钥替换）、重放攻击、密文篡改检测 |
| **隐私** | 服务端日志含明文数据、API 响应泄露敏感信息 |

|------|------|

## 4. 性能测试

### 4.1 基准指标

| 场景 | 并发数 | 目标 (P99) | 失败率上限 |
|------|--------|------------|------------|
| 登录 API | 1000/s | < 500ms | 0.1% |
| 文件列表 (1000 文件) | 500/s | < 200ms | 0.1% |
| 4MB 块上传 | 500/s | < 3s | 0.5% |
| 4MB 块下载 | 1000/s | < 1s | 0.5% |
| 创建共享链接 | 200/s | < 500ms | 0.1% |
| 同步检测 (1000 文件) | 100/s | < 2s | 0.1% |

### 4.2 压力测试

| 场景 | 条件 | 通过标准 |
|------|------|----------|
| 持续高负载 | 2x 正常负载持续 1 小时 | 无 OOM、无请求丢失、P99 不恶化 |
| 突发流量 | 30 秒内从 0 → 10x 正常负载 | 自动扩容生效，无 5xx |
| 大文件上传 | 100GB 文件上传 | 无超时、无内存溢出、可断点续传 |
| 单用户百万文件 | 100 万文件列表 | 加载 < 5s、搜索 < 1s |
| 存储池满 | 磁盘使用率达 95% | 触发告警 + 拒绝新上传 + 已有文件可下载 |

### 4.3 性能测试工具配置

```yaml
# k6 测试脚本模板
import http from 'k6/http';

export const options = {
  stages: [
    { duration: '2m', target: 100 },   # 热身

  ],
  thresholds: {
    'http_req_duration{name:upload}:p(99)': ['max<3000'],
    'http_req_duration{name:download}:p(99)': ['max<1000'],
    'http_req_failed': ['rate<0.005'],
  },
};
```

## 5. CI/CD 流水线

### 5.1 流水线阶段

```
Commit/Push → [Lint] → [Unit Tests] → [Build] → [Image Scan] → [Deploy Dev]
                                                                    │
                              ┌─────────────────────────────────────┘
                              ▼
PR 创建 → [Integration Tests] → [Contract Tests] → [Code Review]
                                                          │
                              ┌───────────────────────────┘
                              ▼
Merge → [Build Release] → [E2E Tests] → [Deploy Staging] → [Smoke Tests]
                                                                    │
                              ┌─────────────────────────────────────┘
                              ▼
                            [Manual Approval Gate]
                                 │
                                 ▼
                        [Deploy Production] → [Health Check] → [Metrics Validation]
```

### 5.2 各阶段详情

| 阶段 | 操作 | 超时 | 失败处理 |
|------|------|------|----------|
| **Lint** | golangci-lint / ESLint / dart analyze | 5 min | 阻断提交 |
| **Unit Tests** | go test / vitest / flutter test | 15 min | 阻断提交 |
| **Build** | Docker image build + push | 10 min | 阻断提交 |
| **Image Scan** | Trivy 漏洞扫描 | 5 min | Critical → 阻断 |
| **Integration** | dockertest + Pact | 20 min | 阻断 PR |
| **E2E** | Playwright (Chrome/Firefox/Safari) | 30 min | 阻断发布 |
| **Smoke Test** | 关键 API 冒烟验证 | 5 min | 阻断生产发布 |

### 5.3 环境策略

| 环境 | 用途 | 数据 | 更新频率 |
|------|------|------|----------|
| **dev** | 开发自测 | 模拟数据 | 每次 push |
| **staging** | 集成验证 + E2E | 脱敏生产数据 | 每个 PR merge |
| **production** | 线上服务 | 真实数据 | 人工审批后 |
