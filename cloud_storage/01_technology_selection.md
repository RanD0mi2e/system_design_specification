# 技术选型：云存储产品

## 概述

本文档定义类 MEGA 云存储产品的完整技术选型方案，覆盖 Web 前端、移动端、后端服务、存储基础设施、数据加密、消息中间件、CDN 分发及 DevOps 工具链。选型原则：优先选择高性能、开源可控、社区活跃、适配零知识加密架构的技术栈。

---

## 1. 前端技术栈

### 1.1 Web 前端

| 维度 | 选择 | 理由 |
|------|------|------|
| **框架** | React 18 + TypeScript | 生态丰富，虚拟 DOM 适合复杂文件管理 UI，社区有成熟的 Web Crypto 集成方案 |
| **状态管理** | Zustand | 轻量、无模板代码、内置持久化中间件，适合管理加密密钥/上传队列等全局状态 |
| **路由** | React Router v6 | 嵌套路由支持文件浏览器布局，懒加载优化首屏 |
| **构建工具** | Vite | 快速 HMR，ESBuild 构建，支持 WASM 模块（加密库） |
| **UI 组件** | Radix UI + Tailwind CSS | 无样式侵入、无障碍友好，自定义文件管理组件 |
| **文件处理** | File System Access API + Web Workers | 大文件流式读写，Worker 线程执行加密/哈希避免阻塞 UI |
| **加密** | Web Crypto API + libsodium-wasm | 浏览器原生 AES-256-GCM 硬件加速；libsodium 提供 X25519+Ed25519 密钥交换与签名 |

### 1.2 移动端

| 维度 | 选择 | 理由 |
|------|------|------|
| **框架** | Flutter 3.x (Dart) | 单代码库覆盖 iOS/Android，高性能渲染，Platform Channel 调用原生加密 API |
| **状态管理** | Riverpod | 编译时安全，无上下文依赖，适合复杂异步任务（上传/下载队列） |
| **本地存储** | drift (SQLite) | 类型安全的本地数据库，存储文件元数据与同步状态 |
| **加密** | flutter_sodium + pointycastle | libsodium 平台绑定，纯 Dart 加密补充 |
| **文件系统** | path_provider + flutter_file_picker | 跨平台文件路径与选择器 |

## 2. 后端技术栈

### 2.1 核心服务

| 维度 | 选择 | 理由 |
|------|------|------|
| **语言** | Go 1.22+ | 高并发（goroutine）、内置 HTTP/2、静态编译镜像小，适合文件流处理 |
| **Web 框架** | gin | 高性能路由、中间件生态成熟、错误处理清晰 |
| **RPC 框架** | gRPC + protobuf | 微服务间高性能通信，支持流式传输（分块上传代理） |
| **API 网关** | Envoy + 自研控制面 | 支持 gRPC/HTTP 双协议，内置限流与 TLS 终止 |
| **认证** | JWT (Ed25519) + OAuth 2.0 | 无状态认证，Ed25519 签名体积小验证快；支持第三方登录 |

### 2.2 微服务划分

| 服务 | 职责 | 技术 |
|------|------|------|
| **auth-service** | 注册、登录、JWT签发/刷新 | Go + PostgreSQL |
| **metadata-service** | 文件/文件夹/版本元数据 CRUD | Go + PostgreSQL |
| **storage-proxy** | 客户端上传/下载代理，分块聚合 | Go + MinIO |
| **sharing-service** | 共享链接生成/验证/权限管理 | Go + PostgreSQL |
| **sync-service** | 变更检测、同步差异计算、冲突解决 | Go + Redis |
| **notification-service** | WebSocket 推送、邮件通知 | Go + NATS |
| **thumbnail-service** | 图片/视频缩略图生成 | Go + FFmpeg |

## 3. 存储基础设施

### 3.1 对象存储

| 维度 | 选择 | 理由 |
|------|------|------|
| **引擎** | MinIO | S3 兼容、开源、支持纠删码、单集群可扩展至 EB 级 |
| **分块大小** | 4MB | 平衡上传重试粒度与 HTTP 开销，匹配 MEGA 设计 |
| **数据冗余** | Reed-Solomon Erasure Coding (12+4) | 容忍 4 块磁盘故障，存储开销仅 33% |
| **加密存储** | 服务端 AES-256-GCM 透明加密 | MinIO 内置，加密已加密的用户数据（双层加密） |

### 3.2 数据库

| 维度 | 选择 | 理由 |
|------|------|------|
| **关系型** | PostgreSQL 16 | ACID 事务、JSONB 支持、全文搜索、成熟的高可用方案（Patroni） |
| **缓存** | Redis 7 (Cluster) | 会话管理、上传进度、热点元数据缓存、分布式锁 |

### 3.3 PostgreSQL 高可用

| 组件 | 选择 |
|------|------|
| **HA 方案** | Patroni + etcd |
| **连接池** | PgBouncer |
| **备份** | pgBackRest（全量+增量） |

## 4. 加密技术栈

### 4.1 零知识加密体系

| 层级 | 算法 | 用途 |
|------|------|------|
| **密码派生** | Argon2id (OPSLIMIT=4, MEMLIMIT=128MB) | 用户密码 → 认证密钥 + 主密钥加密密钥 |
| **主密钥** | X25519 密钥对 | 每个用户唯一，私钥由密码加密存储 |
| **文件密钥** | AES-256-GCM (随机生成) | 每文件独立密钥 |
| **文件加密** | AES-256-GCM (CTR模式，64KB分块) | 文件内容加密，支持随机访问解密 |
| **密钥封装** | ECDH over Curve25519 | 共享场景下的文件密钥交换 |
| **完整性** | SHA-256 Merkle Tree | 文件分块完整性校验 |
| **签名** | Ed25519 | 文件元数据签名，防篡改 |

### 4.2 密钥派生流程

```
用户密码 ──[Argon2id]──→ 派生密钥 (256-bit)
                              │
                ┌─────────────┼─────────────┐
                │                           │
          认证密钥 (前128bit)       主密钥加密密钥 (后128bit)
          (用于登录验证)           (用于解密服务端存储的加密主密钥)
```

### 4.3 客户端库选型

| 平台 | 加密库 | 说明 |
|------|--------|------|
| **Web** | Web Crypto API + libsodium.js | AES 硬件加速，X25519 用 libsodium |
| **Flutter (iOS/Android)** | flutter_sodium | libsodium 移动端绑定 |
| **后端验证** | Go crypto + libsodium-go | 仅处理公钥操作，不解密文件 |

## 5. 文件传输

| 维度 | 选择 | 理由 |
|------|------|------|
| **协议** | HTTPS/2 (HTTP/2) | 多路复用、Server Push、二进制分帧 |
| **上传方式** | 分块上传 (Chunked Upload) | 断点续传、并行上传块、校验独立 |
| **断点续传** | tus 协议扩展 | 标准化的可恢复上传方案 |
| **数据校验** | 块级 SHA-256 + 文件级 Merkle Root | 每块独立校验，最终合并时验证根哈希 |

---

## 6. 消息队列与事件驱动

| 维度 | 选择 | 理由 |
|------|------|------|
| **消息队列** | NATS JetStream | Go 原生、低延迟、支持持久化与流式消费 |
| **事件驱动** | NATS 主题 + 订阅组 | 文件修改事件 → 同步服务 → 通知服务解耦 |
| **异步任务** | Asynq (Redis-based) | 缩略图生成、病毒扫描、文件过期清理 |

| 维度 | 选择 | 理由 |
|------|------|------|
